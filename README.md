# 成长同步 · 学生空间

这是学生成长同步网站的第一版静态原型，面向 GitHub Pages 免费发布。

当前版本包含：

- 学生演示登录（S001 / S002 / S003）
- 我的方向
- 我已经做到的事
- 我正在发生的变化
- 当前 10 分钟微行动
- 成长证据展开
- 学生回应回执
- 成长记录时间线

> 当前登录和数据是前端演示数据，不用于真实账号或生产环境。真实密码、学生隐私资料和后端同步服务不会放在公开仓库。

## 本地预览

```bash
python3 -m http.server 4188
```

然后打开 `http://127.0.0.1:4188/`。
